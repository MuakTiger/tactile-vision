# 하드웨어 실측 제원

STL 원본에서 직접 측정한 값. 논문의 장치(Apparatus) 절에 그대로 쓸 수 있다.

측정 방법: 바이너리 STL 파싱 → union-find로 정점 공유 기반 독립 바디 분리 →
바운딩박스 산출. 피니언 잇수는 XY 평면 투영 후 각도별 최대반지름 프로파일의
FFT 우세 주기로 검출.

측정 대상: `hardware/full/7_22 set_final.stl`, `hardware/parts/{rack,pinion,servo_bracket}.stl`
측정일: 2026-09-22

## 촉각 배열

| 항목 | 값 | 비고 |
|---|---|---|
| 그리드 | 6 열 × 4 행 = 24 셀 | full.stl에서 독립 바디 25개 = 베이스판 1 + 서보유닛 24 확인 |
| 열 피치 (가로) | **30.0 mm** | 6개 위치, 간격 편차 0.00mm |
| 행 피치 (세로) | **40.0 mm** | 4개 위치, 간격 편차 0.00mm |
| 배열 스팬 | 150.0 × 120.0 mm | 중심~중심, 종횡비 **1.25** |
| 베이스판 | 200.0 × 173.0 × 34.75 mm | |
| 전체 높이 | 62.30 mm | |
| 서보유닛 | 27.0 × 20.0 × 27.3 mm × 24 | 크기 편차 < 0.5mm |

배열 종횡비 1.25는 카메라 시야 크롭 종횡비를 결정한다. 불일치 시 셀이 담당하는
화각이 수평/수직 방향으로 비등방이 된다.

### 피니언 제원 유도

FFT 우세 주기 = 12 (강도 950.6 / 2차 조화 24는 454.2로 절반 이하 → 잇수 12 확정).

```
모듈 m   = OD / (z + 2) = 18.68 / 14 = 1.3334
피치원 D = m × z        = 16.00 mm
검산     OD = 1.3333 × 14 = 18.667 mm   vs  실측 18.68 mm  → 일치
```

피치원 16.00mm는 설계 의도된 정수값으로 판단된다.

### 핵심 변환 상수

```
1회전 이동량  = π × 16.00      = 50.265 mm
단위 변환     = 50.265 / 360   = 0.139626 mm/°
역변환                          = 7.1620 °/mm
```

## 단계 수 결정

손바닥 높이차 식별 한계(JND)를 2.5mm로 가정하면:

```
레벨 0을 0mm, 레벨 L-1을 20.9mm로 두면 간격 수는 L-1개
조건: 20.9 / (L-1) ≥ 2.5   →   L ≤ 9.36   →   L_max = 9
```

**채택: 8단계** (간격 2.99mm, JND 대비 1.20배 여유)

8단계는 프로토콜에서 4비트에 들어가므로 남은 4비트를 위험도 채널로 쓸 수 있다.
JND 2.5mm 가정은 실험 RQ3에서 검증 대상이며, 결과에 따라 6~9단계로 조정한다.

## 전원 (미검증 — 확인 필요)

| 항목 | 값 |
|---|---|
| 배터리 | 3S1P (11.1 V 공칭 / 12.6 V 만충) |
| 강압 | 벅 컨버터 → 5 V |
| SG90 이동 전류 | 약 250 mA/개 (실측 필요) |
| 24개 동시 이동 | 약 6 A = 30 W @ 5V |

**벅 컨버터 정격이 확인되지 않았다.** 정격 미달 시 브라운아웃 → Pico 리셋 →
서보 슬램의 악순환이 발생한다. 소프트웨어 완화책은 적용되어 있다:

- 8단계 양자화로 불필요한 미세 이동 제거 (실측 떨림 442 → 0.15 회/분/서보)
- `safety.max_simultaneous_moves`로 동시 이동 서보 수 상한 (2026-10-04부터 24개 = 전부 동시, 약 6.0 A;
  이전 기본 8개 ≈ 2.0 A)
- 펌웨어 슬루 제한 4 tick/5ms로 돌입 전류 억제
- 기동 시 채널당 25ms 시간차 홈 복귀
- `hazard.max_jitter_cells`로 동시 진동 셀 수 상한 (기본 6개)
