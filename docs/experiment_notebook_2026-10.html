절차

$PY -B tools/servo_updown_test.py --cycles 1
git log -1 --format='%h %ad %s' --date=short

  2. 장치를 책상에 고정하고 카메라가 먼 벽을 보게 해요. 벽까지 4 m 이상이면 가운데 칸이 단계 0에서 시작해요. 더 가까우면 시작 단계만 메모하면 돼요.

    판은 끈에 매달아, 떨어뜨리면 렌즈 앞 0.5 m에서 화면 가운데를 가리고 멈추게 끈 길이를 맞춰요.

  3. 판이 지나가는 옆에 막대를 세우고 렌즈 높이 + 9 cm에 테이프를 붙여요. 판 아래 끝이 이 선을 지나는 프레임이 0 ms예요. 내릴 때와 올릴 때 같은 선을 써요. 막대는 장치 카메라 화면 밖에 둬요.

  4. 슬로모션(240 fps)으로 두고, 패드 뒤 위쪽에서 패드 너머로 판이 보이게 고정해요. 칸 9 핀이 크게 보이고 판 아래 끝과 기준선이 같은 화면에 들어오면 돼요. 핀 옆에 자를 세우고 조명은 밝게 해요.

  5. 핀이 움직여요. 손을 패드에서 떼세요.

    $PY -B run.py

  6. 녹화 시작 → [판 내리기 → 3초 → 판 올리기 → 5초] × 10 → 녹화 정지

  7. 같은 방법으로 10회.

  8. 같은 방법으로 10회.

  9. 터미널에서 Ctrl+C를 누르면 핀이 천천히 내려가요. 그다음 로그를 다른 이름으로 복사해요.

    cp logs/metrics.csv logs/metrics_$(date +%m%d_%H%M)_latency.csv

  10. 케이블로 아이폰의 원본 파일(DCIM 폴더)을 그대로 복사해요. 일반 속도로 변환된 파일은 쓰지 않아요.

거리 정확도

장치 카메라로 찍은 사진에서 모델이 추정한 거리를, 줄자로 잰 실제 거리와 비교합니다. 같은 사진에 실내·실외 모델을 둘 다 돌려 모델별 배율을 구해요. 분석은 사진만 있으면 나중에 할 수 있어요.

완료 기준실내 6거리 + 실외 6거리, 거리마다 숫자 종이 1장 + 판 3장 (모두 48장)

준비물

절차

  1. C920을 노트북에 꽂고 윈도 카메라 앱의 Pro 모드에서 초점을 가장 먼 쪽 끝으로 고정해요. 자동 초점은 끄고, 사진 비율은 16:9(1280×720 또는 1920×1080)로 해요.

    촬영하는 동안 초점은 건드리지 않아요. 가까운 판이 조금 흐린 건 정상이에요. 장치도 같은 초점이에요.

  2. 렌즈 높이 1.0 m, 수평, 정면. 렌즈 바로 아래 바닥을 0으로 하고 거리마다 바닥에 테이프를 붙여요. 거리는 렌즈 앞면에서 판 앞면까지예요.

  3. 거리마다 숫자 종이를 판에 대고 1장 → 종이를 떼고 판만 3장. 사진 사이에는 판을 들었다가 다시 놓아요. 판 가운데가 렌즈 높이에 오고 카메라를 똑바로 보게 해요.

  4. 같은 방법으로 찍어요. 판이 바람에 흔들리지 않게 잡아 두세요.

  5. 실내·실외 폴더로 나누고 장소, 시각, 날씨를 메모해요. 보조자가 있으면 실외에서 판 대신 사람이 같은 거리에 서서 3장씩 더 찍어요(선택).

주의

  • 꼭 장치의 C920으로 찍어요. 다른 카메라는 화각이 달라서 거리 배율도 달라져요.
  • 판이 작으면 먼 거리에서 칸 넓이의 10%를 못 채워, 장치가 쓰는 칸 대표 거리에 잡히지 않아요. 50×70 cm보다 작게 하지 않아요.
  • 10/12~13에 찍은 영상은 실제 거리 기록이 없으면 쓰지 않아요.
  • 노트북에서 초점이 고정되지 않으면 실내만 젯슨과 모니터로 찍어 두세요(s 키로 저장, 초점 0 자동 고정). 실외 방법은 그다음에 정해요.
cd ~/tactile-vision
~/sensory_substitution/venv/bin/python -B tools/cam_raw.py --size 1280x720

  1. 참여자는 안대를 쓰고 출발선 뒤에서 벽 쪽을 보고 서 있어요. 배치를 보지 않아요.

  3. "출발" — 보조자가 초시계를 누르고 뒤따르며 촬영해요.

  • 장치만(D) 쓸 때는 지팡이가 없어 45 cm 상자에 걸려 넘어질 수 있어요. 보조자가 특히 가까이 붙어요.
  • 시작 전에 LiPo 전압과 배선을 확인하고, 뜨거워지면 바로 멈춰요.
  • IRB 답이 '안 된다'면 정지 감지 시험만 하고 보행은 하지 않아요.

기록 규칙

  • 원본(영상·사진·로그)은 지우거나 덮어쓰지 않아요. '날짜_실험' 폴더에 그대로 둬요. 예: 1015_반응시간
  • run.py는 실행할 때마다 logs/metrics.csv를 새로 써요. 끝나면 바로 다른 이름으로 복사해요.
  • 종이 기록은 사진을 찍어 두세요. 나중에 분석용 CSV로 옮길 때 써요.
  • 그날 쓴 설정을 메모해요: 코드 버전(git log -1), 보정 전/후, 장소, 시각.
  • 분석 폴더의 make_example_data.py는 다시 돌리지 않아요. 실측 CSV를 덮어써요.
  • 얼굴이 나온 영상·사진은 공개 저장소에 올리지 않아요.
