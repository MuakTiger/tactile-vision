`docs/hardware_measured.md` 참조. 논문 기재용 요약:

**병목은 서보 기계적 이동(416 ms)이며 연산 전체(27.1 ms)의 15.3배다.**
이 사실이 설계 전반을 규정한다:

- 깊이 추론을 67 fps로 돌릴 수 있어도 촉각 갱신률은 액추에이터가 제한한다.
- 따라서 전송률을 15 Hz(주기 67 ms)로 묶는다. 1단계 이동 59 ms ≈ 16.8 Hz와 정합.
- 67 ms 예산 대비 연산 27.1 ms → **여유 39.6 ms (59%)**. 이 여유를 위험도 검출에 썼다.

> **2026-10-03 변경.** 깊이 입력을 924×504로 올리고(연산 프레임당 중앙 64 ms, 초당 15.3 프레임,
> YOLO26n·Places365 2 Hz 포함) 박자는 Pico가 정한다: 젯슨은 결과가 나올 때마다 보내고, Pico 펌웨어 v3가
> `transport.pin_rate_hz`(기본 5 Hz)마다 최신 값 하나만 적용한다. 위의 15 Hz·여유 59% 계산은 이전 구성 기준이다.
> 실측 원자료: `logs/bench_2026-10-03/`.

**측정 시 주의** (실험 재현 시 필수)

ultralytics는 첫 `predict` 호출에서 predictor를 구성하고 TRT 엔진을 역직렬화한다
(수 초 소요). 예열하지 않고 측정하면 초기 프레임이 실시간 경로를 막아
60프레임 평균이 37 ms → 180 ms로 튄다. `Pipeline.warmup()`이 깊이·위험도 엔진을
모두 예열한 뒤 통계를 초기화한다.

## 3. RQ1 — 매핑 함수가 거리 판단에 미치는 영향 (C1)

### 가설
H1a: metric+로그 매핑은 상대(프레임별) 매핑보다 거리 추정 절대오차가 작다.
H1b: metric+로그 매핑은 장면이 바뀌어도 같은 핀 높이가 같은 거리를 뜻한다.

### 설계
피험자 내(within-subject) 3조건 × 반복. 조건 제시 순서는 라틴방격으로 상쇄.

| 조건 | 설정 |
|---|---|
| A (제안) | `mapping.mode=log`, near 0.5m, far 8.0m, 8단계 |
| B (기저선) | `mapping.mode=relative_ema` |
| C (절제) | `mapping.mode=linear`, near 0.5m, far 8.0m |

조건 전환은 실행 인자만 바꾼다: `python run.py --mapping log|relative_ema|linear`

### 과제
1. 피험자는 눈을 가리고 양손을 패드에 올린다.
2. 정면에 평면 장애물(폼보드 1.0×1.5m)을 지정 거리에 배치한다.
   거리 집합: {0.6, 0.9, 1.3, 1.8, 2.5, 3.5, 5.0} m — 로그 간격.
3. 3초 제시 후 피험자가 거리를 구두 보고한다.
4. 각 거리 × 3반복 × 3조건 = 63 시행/피험자.

### 배경 장면 조작 (H1b 검증의 핵심)
같은 장애물 거리에서 **배경 깊이 분포만** 바꾼다.

| 배경 | 구성 |
|---|---|
| 좁은 배경 | 장애물 뒤 1m에 벽 (장면 깊이 범위 좁음) |
| 넓은 배경 | 복도 (장면 깊이 범위 10m 이상) |

상대 매핑은 배경에 따라 같은 거리를 다른 핀 높이로 출력한다. 시뮬레이션 실측:
같은 레벨 4가 복도 4.63m / 벽앞 1.97m / 로비 11.35m — **장면간 5.75배 변동**.
반면 metric+로그는 1.09배. 이 차이가 피험자 보고에 나타나는지 확인한다.

### 측정 지표
- 주 지표: 거리 추정 절대오차 |보고 − 실제| (m), 상대오차 (%)
- 부 지표: 같은 실제거리에 대한 배경조건 간 보고 차이 (일관성)
- 부 지표: 응답 시간 (s)

### 분석
- 2-way 반복측정 ANOVA: 매핑조건(3) × 실제거리(7)
- H1b는 매핑조건 × 배경조건 상호작용으로 검정
- 사후검정 Bonferroni 보정

### 피험자
정상 시력 성인 12명 (눈가림). 시각장애인 피험자 확보가 가능하면 별도 소집단으로 추가.

## 4. RQ2 — 손바닥 높이 식별 한계와 최적 단계 수 (C2)

이 실험이 **8단계라는 설계 선택의 근거**를 만든다. 현재는 문헌 기반 JND 2.5mm
가정에서 유도했으며, 직접 측정하면 기여가 된다.

### 가설
H2: 손바닥의 핀 높이차 JND는 2~3mm 범위이며, 스트로크 20.9mm에서 신뢰성 있게
구분 가능한 단계 수는 6~9이다.

### 설계 — 2구간 강제선택 (2AFC)
1. 단일 셀(중앙부 ch9)을 높이 h1로 제시 (2초) → 홈 복귀 (1초) → 높이 h2 제시 (2초).
2. 피험자가 "두 번째가 더 높다/낮다"를 답한다.
3. Δh ∈ {0.5, 1.0, 1.5, 2.0, 2.5, 3.0, 4.0, 5.0} mm, 기준 높이 3수준
   (하단 5mm / 중간 10mm / 상단 16mm) — 위치에 따른 차이 확인.
4. 각 조건 20시행 → 심리측정 함수 피팅 → 75% 정답 지점을 JND로 정의.

도구: `python tools/calibrate_pins.py` 의 raw tick 인가 기능으로 임의 높이 제시 가능.
tick 분해능 0.0646mm이므로 0.5mm 단계 제시에 충분하다.

### 측정 지표
- JND (mm), 기준 높이별 JND 변화 (Weber 분율)
- 손바닥 부위별 차이: 행 0~3은 손목~손가락 밑동에 걸쳐 있어 감도가 다를 것으로 예상

### 주의 — 행별 감도 불균일
배열 세로 스팬 120mm는 성인 손바닥 길이(약 100mm)를 넘는다. 상단 행이
손가락 기저부에 닿으면 손바닥보다 민감하다. 이는 통제 변수로 기록하고,
필요 시 행별 매핑 이득을 다르게 두는 후속 설계로 연결한다.

## 5. RQ3 — 비대칭 시간 필터 (C3)

### 가설
H3a: 비대칭 필터는 대칭 필터와 같은 떨림 억제 성능을 유지하면서 접근 검출 지연을 줄인다.
H3b: 필터가 정지 장면에서 서보 활동을 99% 이상 줄인다.

### 이미 확보된 시뮬레이션 결과 (`tools/test_mapping.py`)

| 필터 | 정지장면 서보 이동 | 접근 지연 |
|---|---|---|
| 없음 | 442.4 회/분/서보 | — |
| 대칭 EMA만 | 238.1 회/분/서보 | — |
| 비대칭 EMA | 173.5 회/분/서보 | — |
| 대칭 전체 | — | 24.7 cm |
| **비대칭 전체 (채택)** | **0.15 회/분/서보** | **9.7 cm** |

추가 검증된 거동:
- 급접근(7.0m→0.55m): 1프레임에 3단계 즉시 상승 (안전 반응)
- 급후퇴(0.55m→7.0m): 1단계씩만 하강, 레벨1까지 933ms (급락 방지)

### 실기기 검증 절차
1. 카메라를 삼각대에 고정, 정지 장면 60초 녹화 → 오프라인 재생으로 필터별 서보 이동 횟수 집계
2. 보행 접근 시나리오 녹화 (1.0 m/s로 벽에 접근) → 레벨 전이 시점의 실제 거리 측정
3. 지표: 서보 이동 횟수/분, 레벨 전이 거리 오차 (cm), 전류 피크 (측정 가능 시)

재현성 확보: `--source` 인자로 같은 영상에 다른 필터를 적용하고,
`logs/metrics.csv`의 셀 거리·레벨 시계열을 비교한다.

## 6. RQ4 — 진폭·진동 이중 채널 (C4)

### 가설
H4a: 위험도 진동(jitter)은 거리 판단 정확도를 유의하게 떨어뜨리지 않는다(간섭 없음).
H4b: 피험자는 진동 유무로 위험 객체 존재를 80% 이상 정확히 판별한다.

### 설계
2×2 피험자 내: {진동 있음/없음} × {위험 객체 있음/없음}

과제: 장애물 거리 보고 + "위험 객체가 있었는가" 응답을 동시에 수행.

- H4a는 진동 조건에서의 거리오차를 무진동 조건과 비교
- H4b는 위험 판별 d' (신호검출이론)

### 진동 파라미터 (실측 근거)
SG90 부하 속도 360°/s 제약으로 촉각 최적 대역(20~50Hz)은 낼 수 없다.
펌웨어 v3(2026-10-03): 진동을 핀 갱신 박자에 맞춘다 — 박자(기본 200 ms)의 2·4번째 1/4 구간에
위험 셀을 비켜 놓아 초당 10회(박자의 2배). 진폭은 위험도 1/2/3 → 1/2/3도(`hazard.jitter_deg`,
tick 2/4/6), 홈 쪽으로(맨 아래 핀은 위로). 1도는 SG90 데드밴드 근처라 실기에서 최소 감지 진폭을 확인해야 한다.
(이전 v2: 반주기 75 ms → 6.7 Hz, 진폭 1.0/1.5/2.0 mm = tick 15/23/31.)

전류 제약으로 동시 진동 셀은 6개로 제한된다(`hazard.max_jitter_cells`).
위험 셀이 6개를 넘으면 가까운 것부터 남긴다 — 이 정책 자체도 보고할 설계 결정이다.

### COCO 위험도 지정
`config/default.yaml`의 `hazard.danger_levels`. 3=즉시위험(차량, 계단),
2=주의(사람, 가구), 1=참조(신호등, 소형물체). 이 배정의 타당성은 별도
전문가 평정(시각장애 보행 지도사 등)으로 보강하면 좋다.

## 7. RQ5 — 보행 과제 (C5, 주 결과)

### 가설
H5: 장치 사용 시 무보조 조건 대비 충돌 횟수가 감소하고 보행 속도가 증가한다.

### 설계
피험자 내 3조건, 순서 상쇄:

| 조건 | 설명 |
|---|---|
| 무보조 | 눈가림, 보조 없음 |
| 흰지팡이 | 눈가림, 지팡이 (실무 기저선) |
| 제안 장치 | 눈가림, 촉각 패드 |

### 코스
길이 15m 실내 복도. 장애물 6개를 배치하되 조건마다 배치를 바꿔 학습 효과를 상쇄.
- 바닥 장애물 (박스, 높이 40cm) × 2
- 흉부 높이 장애물 (테이블 모서리) × 2
- 통로 협착 (폭 80cm) × 1
- 벽 정면 접근 (막다른 길) × 1

머리/흉부 높이 장애물은 지팡이가 검출하지 못하는 유형이므로, 장치의 차별적
이점이 드러나는 지점이다. 이 대비를 명시적으로 설계에 넣는다.

### 측정 지표
| 유형 | 지표 |
|---|---|
| 주 지표 | 충돌 횟수 (접촉 1회 = 1) |
| 주 지표 | 완주 시간 (s), 평균 보행 속도 (m/s) |
| 부 지표 | 장애물별 회피 개시 거리 (m) — 영상 분석 |
| 부 지표 | 궤적 편차 (중심선 대비 RMS) |
| 주관 | NASA-TLX (정신적 부하), 사용성 5점 리커트 |
| 학습 | 세션 1 vs 세션 3의 성능 변화 |

### 훈련 프로토콜
감각대체는 학습이 필요하다. 훈련 없는 결과는 장치 성능을 과소평가한다.
- 세션 0 (20분): 정지 상태에서 단일 장애물 거리 맞추기 (매핑 학습)
- 세션 1 (20분): 정지 장애물 회피 연습
- 세션 2~3 (각 20분): 코스 주행
- 측정은 세션 3에서 수행, 세션 1~2는 학습 곡선으로 보고

### 안전
- 보조자가 항상 피험자 옆에서 동행, 충돌 직전 개입 가능
- 장애물은 모두 완충재로 감쌈
- 중단 요청 시 즉시 종료
- 기관 IRB 승인 필요 (피험자 실험)

## 8. 실행 일정 (3일 초안 기준)

| 일 | 작업 | 산출물 |
|---|---|---|
| 1 | 핀 24채널 캘리브레이션 완료, 전원 실측(벅 정격·전류) | `calib/servo_calib.json`, 전류 측정치 |
| 1 | 카메라 연결 후 실기기 FPS·지연 재측정 | 벤치마크 표 갱신 |
| 2 | RQ2 (JND) 예비 실험 — 본인 + 2명, 단계 수 확정 | JND 추정치, 단계 수 근거 |
| 2 | RQ1 거리 판단 예비 실험 — 3명, 조건 A/B 비교 | 효과 크기 추정, 본실험 표본수 산출 |
| 3 | RQ3 실기기 필터 검증 (녹화 기반) | 서보 이동/분, 접근 지연 실측 |

- 매핑 함수 설계 근거 및 시뮬레이션 비교
- 비대칭 필터 정량 효과 (시뮬레이션)
- 프로토콜 신뢰성 (단일비트 오류 100% 검출)

**초안에서 "계획"으로 제시할 것**
- RQ1·RQ2 본실험 (예비 결과 + 본실험 설계)
- RQ4·RQ5 (설계만)

## 9. 표본 수 산출

예비 실험으로 효과 크기를 추정한 뒤 확정한다. 초기 가정:

- RQ1: 반복측정 ANOVA, 중간 효과 크기 f=0.25, α=0.05, power=0.80, 3조건
  → 약 12명 (G*Power 기준, 상관 0.5 가정)
- RQ2: 심리측정 함수 피팅에는 조건당 20시행 이상 필요. 피험자 8명이면 충분.
- RQ5: 충돌 횟수는 분산이 크므로 최소 15명 권장. 확보 어려우면
  피험자 내 반복 세션 수를 늘려 보완.

## 10. 재현성

모든 실험 조건은 설정 파일과 CLI 인자로만 바뀌며 코드 수정이 필요 없다.

```bash
# 조건 A (제안)
python run.py --mapping log --levels 8

python run.py --mapping relative_ema

# 조건 C (절제)
python run.py --mapping linear

python run.py --source data/trial_03.mp4 --mapping log --no-hw
```

- 하드웨어 상수는 `src/tactile_vision/geometry.py` 한 곳에 있고 STL 측정 근거가
  주석으로 남아 있다.

## 11. 한계 (논문에 명시할 것)

1. **단안 metric 깊이의 절대 정확도**가 거리 판단 성능의 상한을 정한다.
   Hypersim 학습 모델은 실내 도메인에 편향되며 원거리 오차가 크다.
   본 연구에서는 모델 자체 정확도를 별도 검증하지 않았다(향후 RGB-D 기준 대조 필요).
2. **눈가림 정상시력 피험자**는 실제 시각장애인의 촉각 숙련도·보행 전략을
   대표하지 않는다. 결과의 외적 타당도가 제한된다.
3. **8m 이상은 단계 0으로 포화**된다. 개방 공간에서 원거리 구조 파악에 한계가 있다
   (적응형 far bound를 옵션으로 구현했으나 기본 비활성).
4. 배열 세로 스팬(120mm)이 손바닥 길이를 초과해 **행별 감도가 불균일**하다.
5. SG90 기반 구조상 **진동이 초당 10회(v3, 박자의 2배)·1~3도**로 제한된다. 촉각 최적 대역(20~50Hz)을
   쓸 수 없어 위험 채널의 지각 현저성이 낮을 수 있다.
6. 1단계 변화 종단 지연 평균 약 0.26 s, 전체 스트로크 약 0.6 s *(산정치, 2026-10-03 구성)* 는
   빠른 보행(1.4 m/s 이상)에서 부족할 수 있다.
